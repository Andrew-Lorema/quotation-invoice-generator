# Quotation & Invoice Generator

A simple, responsive web application designed to create and manage quotations and invoices efficiently.

## Features
- Generate quotations and invoices.
- Add and remove materials or service items.
- Automatically calculate material subtotals, labour costs, VAT (16%), and the grand total.
- Clear form entries.
- Print or save invoices and quotations as PDF documents.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Getting Started
1. Clone or download this repository.
2. Open `index.html` in your web browser.
3. Enter the relevant quotation or invoice details.
4. Add materials, labour costs, and applicable VAT.
5. Print or save the completed document as a PDF.
